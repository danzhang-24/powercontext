# 摘要

对比表示学习通过构造正负样本对，把语义相近的文本映射到向量空间中彼此靠近的位置。本文讨论其在文献检索场景中的落地方式，重点是如何让向量召回与关键词召回互补。

# 一、对比学习的基本形式

给定锚点样本 $a$、正样本 $p$ 与负样本集合 $\{n_i\}$，InfoNCE 损失写作

$$L = -\log \frac{\exp(\mathrm{sim}(a, p)/\tau)}{\exp(\mathrm{sim}(a, p)/\tau) + \sum_i \exp(\mathrm{sim}(a, n_i)/\tau)}$$

温度系数 $\tau$ 控制分布的尖锐程度，对效果影响很大。

# 二、难负样本挖掘

随机负样本过于简单，模型很快饱和。需要在候选池中挑选与锚点最相似但被标注为负的样本，也就是难负样本挖掘（hard negative mining）。在检索系统中可以直接用线上召回结果作为负样本池，让训练分布与推理分布一致。

# 三、向量召回与关键词召回的互补性

向量召回擅长处理同义改写与跨语言表达，关键词召回则擅长精确匹配专有名词、公式编号与罕见术语。生产系统通常把两路召回结果合并去重，再交给精排模型。

# 四、向量索引的工程取舍

近似最近邻索引在精度与延迟之间取舍。HNSW 适合内存充裕、查询并发高的场景；IVF 类索引在数据量大时更省内存。距离度量的选择同样重要，余弦距离适合归一化向量，L2 距离在未归一化时更稳定。

# 五、评估方式

除了常规的召回率与 NDCG，还要单独统计"向量召回独有问题"与"关键词召回独有问题"，据此决定是否继续投入优化某一路召回。混合排序常用倒数排名融合（RRF），它不依赖两路分数的量纲。

# 六、结论

对比学习让向量召回在语义层面补齐了关键词召回的短板，而混合召回加融合排序是在工程上稳健的默认方案。
