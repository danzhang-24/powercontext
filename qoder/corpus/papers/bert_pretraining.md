# 摘要

本文提出 BERT，一种基于双向 Transformer 的预训练语言表示模型。BERT 先在大规模无标注语料上进行掩码语言模型预训练，再针对具体任务做微调，在多个自然语言理解基准上刷新结果。

# 一、预训练任务

掩码语言模型（MLM）随机选择 15% 的输入 token 进行预测，其中 80% 替换为 [MASK]，10% 随机替换，10% 保持不变。句子对任务则使用下一句预测（NSP）作为辅助目标。双向的掩码预训练让每个位置都能同时利用左右两侧上下文，这是 BERT 与单向语言模型最本质的区别。

# 二、微调阶段

下游任务微调时在预训练模型顶部加一个轻量任务头，所有参数一起微调。句对分类、句子分类与问答任务的实现差异很小，这体现了"预训练 + 微调"范式的通用性。

# 三、输入表示

BERT 的输入由词向量、片段向量与位置向量三部分相加得到。片段向量区分句 A 与句 B，位置向量区分序列中的绝对位置。

# 四、模型规模与训练代价

BERT Base 使用 12 层 Transformer、隐藏维度 768、12 个注意力头，总参数量约一亿；BERT Large 参数量约三亿。训练使用 AdamW 优化器与学习率预热，在多卡环境下需要混合精度训练以控制显存。

# 五、局限

MLM 的 [MASK] token 在预训练与微调之间存在不一致，评测时也依赖人工构造的掩码。后来 ELECTRA 等工作用判别式替换检测缓解这一问题。此外 BERT 的输入长度上限为 512 个 token，长文档处理需要滑窗或分段策略。

# 六、结论

BERT 证明了大规模无监督预训练加少量标注微调可以显著提升自然语言理解性能，并直接推动了预训练语言模型在检索、问答与摘要任务上的落地。
