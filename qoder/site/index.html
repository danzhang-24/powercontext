会记住你在读什么的论文助手

把论文与笔记灌进 seekdb（OceanBase 衍生搜索数据库），用 BM25 全文 + 向量 ANN + 结构化过滤 三路并行检索，再用 PowerContext 记住「研究方向 / 检索历史 / 阅读进度」， 让第二次检索比第一次更准——而且每一步的 SQL 与记忆读写都留痕可查。

要解决的三件事

纯关键词检索和"每次从零开始"的检索体验，是研究者最常遇到的两个坑。

01 / 关键词搜不准

同义、缩写、中英混排 → 频繁漏召回

只用 BM25 的话，"message passing" 和 "消息传递" 是两个世界。 PaperPocket 并行跑向量 ANN 通道，语义相近但字面不同的段落也能捞上来。

02 / 条件说不清

「2019 年以后 + 综述 + gnn 标签」很难表达

年份区间、标签、资料类型全部写进同一条 SQL 的 WHERE， 由数据库执行过滤，不是拉回内存再筛——顺便还能吃到索引。

03 / 每次从零开始

上周的方向，这周还得重新交代一遍

PowerContext 记住研究方向、常用标签、检索历史与阅读进度。 方向参与查询向量扩展，标签与历史参与结果加权，已读的段落直接被剔除。

架构

左侧是语料与导入流水线，中间是 seekdb（全文索引 / 向量索引 / AI 函数）， 右侧是 PowerContext 记忆层，三者由 PaperPocket 门面组装。

能力

每一项都对应一条可以现场复核的证据，而不是一句口号。

full-text

ngram 全文索引（BM25）

FULLTEXT · ngram
中文按二元组建索引，MATCH(title, content) AGAINST(... IN NATURAL LANGUAGE MODE) 直接返回相关度分数，解释得了每一次命中。

vector

HNSW 向量索引（vsag）

VECTOR · L2
l2_distance(emb, '...') APPROXIMATE LIMIT n 走 HNSW 近似最近邻。 向量由 seekdb 内部的 AI_EMBED 函数算出。

structured

结构化过滤在 SQL 层

WHERE
年份区间、标签、资料类型直接写进两条检索 SQL 的 WHERE， 由数据库执行；已读资料依据记忆被剔除。

fusion

RRF 融合 + 记忆加权

RRF_K = 60
BM25 分数量纲与 L2 距离不可直接相加，故用只看名次的 RRF； 记忆乘子 1 + 0.35 × memory_score 上限受控，不会盖过内容相关性。

memory

PowerContext 记忆

/v1/memory
方向参与查询向量扩展，标签 / 历史参与加权，进度剔除已读； 真实 scope_id 落盘，另一个进程也能读回。

ai

seekdb AI 函数

AI_EMBED · AI_COMPLETE
模型端点通过 DBMS_AI_SERVICE 注册到数据库， 向量计算与简报生成都由数据库发起调用，不是 Python 侧代劳。

怎么跑

前置：Python 3.10+、curl，以及一个跑在 127.0.0.1:5881 的 seekdb 实例。

# 在仓库的 qoder/ 目录下执行
cd <仓库根目录>/qoder

# ① 装依赖 → 起 PowerContext Server 与本地模型服务 → 建表建索引
#    → 把模型端点注册到 seekdb（AI_EMBED / AI_COMPLETE）
bash scripts/setup.sh

# ② 端到端演示：导入语料 → 检索 → 写记忆 → 再检索 → 生成简报
#    → 记录阅读进度 → 独立进程读回记忆，并把 SQL / 记忆读写落盘
bash scripts/run_demo.sh

# ③ 验收自检：11 项逐条核对，任何一项不过即非零退出
bash scripts/verify.sh

# ④ 测试
bash tests/run_tests.sh

单独使用 CLI

.venv/bin/python -m paperpocket ingest
.venv/bin/python -m paperpocket search "图神经网络 消息传递 邻居聚合" --top-k 5 --show-sql
.venv/bin/python -m paperpocket search "对比学习" --year-from 2020 --tag gnn
.venv/bin/python -m paperpocket brief "图神经网络 消息传递"
.venv/bin/python -m paperpocket remember --direction "图神经网络 消息传递" --tag gnn
.venv/bin/python -m paperpocket recall
.venv/bin/python -m paperpocket stats
.venv/bin/python -m paperpocket verify
